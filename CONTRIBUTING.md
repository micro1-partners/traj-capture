# Contributing

This repository is public so companies can install the plugin straight from GitHub and
read exactly what runs on their machines. It is maintained by micro1.

* **Bugs and questions:** open an issue.
* **Pull requests:** welcome for fixes; every change needs a maintainer review and a
  green CI run before merge (enforced by branch protection). For anything larger than a
  fix, open an issue first so we can agree on the shape.
* **Tests:** `python -m pytest`, `python -m pytest packages/traj-shipper-py/tests`, and
  `npm test` in `packages/traj-shipper-node`.
